# What I Missed

> Generated by `python scripts/what_i_missed.py` from the evasion tests, gap report, regression corpus
> and behavioural baseline, plus a hand-kept list of what has never been run for real.

Detection engineering work is easy to oversell. This page is the opposite: every known miss in one place.

## 1. Bypasses I found in my own rules (11)

- **SOC-RULE-004**: Abbreviated parameter (-ec) (T1059.001). PowerShell accepts any unambiguous prefix (-e, -ec, -enco). Fix: match a regex such as `\s-e(c|nc|nco|ncod|ncode|ncoded|ncodedc\w*)?\s` instead of fixed strings.
- **SOC-RULE-004**: En dash instead of hyphen (T1059.001). PowerShell treats en/em dashes as parameter prefixes. Fix: match `EncodedCommand` without the dash.
- **SOC-RULE-004**: Renamed powershell.exe (T1036.003). The rule keys on Image. Fix: also match OriginalFileName (Sysmon records it); tracked in GAPS.md as T1036.003.
- **SOC-RULE-005**: Policy registry value via reg.exe (T1562.001). Same effect, different binary. Fix: a registry_set rule on the Defender policy keys (needs Sysmon Event 13).
- **SOC-RULE-001**: PROCESS_ALL_ACCESS (0x1FFFFF) (T1003.001). The rule lists 0x1010, 0x1400 and 0x1F0FFF only. Fix: add 0x1FFFFF and other masks with PROCESS_VM_READ (0x10).
- **SOC-RULE-001**: Source binary named svchost.exe outside System32 (T1036.005). The filter trusts any path ending in \svchost.exe. Fix: filter on the full System32 path.
- **SOC-RULE-019**: Two spaces between verb and object (T1490). The rule matches the literal 'delete shadows'. Fix: contains|all on 'delete' and 'shadows'.
- **SOC-RULE-019**: CIM cmdlets instead of WMI Delete() (T1490). The PowerShell branch needs the word 'Delete'. Fix: also accept Remove-CimInstance / Remove-WmiObject.
- **SOC-RULE-039**: Renamed rclone, custom remote name (T1567.002). Remote names are user-defined in rclone.conf. Fix: match OriginalFileName/hash of rclone, or network telemetry.
- **SOC-RULE-014**: Alternative download verb (-verifyctl) (T1105). certutil can fetch URLs with several verbs. Fix: also match 'http' in the command line of certutil.
- **SOC-RULE-014**: Renamed certutil.exe (T1036.003). Keyed on Image only. Fix: also match OriginalFileName.

Details and the detected variants: [EVASION.md](EVASION.md).

## 2. Techniques with no rule (9)

- **T1018** Remote System Discovery: High benign volume from admin tooling; not yet tuned
- **T1021.001** Remote Services: Remote Desktop Protocol: Legitimate RDP is constant in the lab; needs a baseline of normal source/destination pairs (F13)
- **T1027** Obfuscated Files or Information: Only the encoded-PowerShell sub-case is covered (SOC-RULE-004); file-level obfuscation needs content inspection (YARA, F70)
- **T1036.003** Masquerading: Rename System Utilities: Needs OriginalFileName in process telemetry and a rule comparing it to Image
- **T1048** Exfiltration Over Alternative Protocol: Zeek ingest exists (F72); volume-based exfiltration needs per-host byte baselines not built yet
- **T1055** Process Injection: Needs kernel ETW (Microsoft-Windows-Threat-Intelligence); Sysmon does not see thread-context changes
- **T1190** Exploit Public-Facing Application: Needs web/WAF logs; the lab has no public-facing application
- **T1555.003** Credentials from Password Stores: Credentials from Web Browsers: Needs Sysmon file-access auditing on browser profile paths (SACLs), not collected in the lab
- **T1557.001** Adversary-in-the-Middle: LLMNR/NBT-NS Poisoning: Zeek ingest exists (F72) but no rule yet: needs LLMNR/NBT-NS traffic in conn.log and a baseline of name-resolution responders

Source: [coverage/GAPS.md](coverage/GAPS.md).

## 3. Attacks reported under the wrong name (1)

The rule written for these attacks matches, but another rule ranks first (higher severity, or the same
severity and a lower rule id), so the analyst sees a less specific title; the more specific rule is
only listed in `also_matched`.

## 4. Signals that do not work yet

- Rare parent-child baseline: flags 26/26 benign near-miss samples as well as the attacks, because the synthetic baseline has only 4 distinct pairs ([BEHAVIORAL_BASELINE.md](BEHAVIORAL_BASELINE.md)).
- Threshold tuning: no correlation rule receives any benign events from the synthetic baseline, so their thresholds are untuned ([THRESHOLD_TUNING.md](THRESHOLD_TUNING.md)).
- False positives: the baseline reaches zero only because two exceptions written for that same baseline suppress 119 matches ([VALIDATION_RESULTS.md](VALIDATION_RESULTS.md)).

## 5. Never verified end to end (16)

- Container images: `compose.yaml` and `deploy/docker-compose.yml` pass `docker compose config`, but no image has been built or run here (Docker daemon unavailable).
- Vagrant and Ansible lab provisioning (`deploy/vagrant`, `deploy/ansible`): neither tool was installed.
- `sigma check` (sigma-cli) on the rules, including the correlation files: runs in CI only; the local install failed.
- GitHub Actions: workflows are written and linted locally; whether CI is green on GitHub is unknown here.
- Live VirusTotal / AbuseIPDB enrichment: implemented and opt-in, never called with a real key.
- OTX, URLhaus, GreyNoise, Shodan and Censys lookups: built to each API's documentation, tested with stubs, never called with a real key.
- TheHive / Cortex, MISP, Shuffle / n8n, CIPHER feeds and GUARDIAN: request and payload formats tested with stubs and fixtures, never exchanged with a running instance.
- Entra ID (Graph) responder, email quarantine, SMTP user notifications and Slack / Telegram ChatOps: tested with stub clients, never run against a real tenant, mailbox or chat workspace.
- CAPE sandbox, osquery (Fleet) and Velociraptor live queries, yara-python: tested with stubs; no live sandbox, fleet or yara-python install.
- Zeek and Suricata ingest: tested on synthetic log records, no live sensor connected.
- LLM triage summary (Claude API): request shape tested with a stub client; no live API call made and summary quality not measured.
- SIEM conversions in `rules/converted/` (Splunk, Elastic, KQL, Wazuh): generated and syntax-checked where possible, never loaded into a real SIEM.
- Prometheus scrape and Grafana dashboards (`deploy/monitoring`): config only.
- Caldera report import: tested on a hand-written fixture, not a real Caldera export.
- Atomic Red Team: no real atomic test has been run against the lab; mapping tested on a fixture.
- Every detection result in this repo: synthetic events written by the rule author. No real attack, no real benign traffic.
