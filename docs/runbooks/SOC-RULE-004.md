# Runbook: SOC-RULE-004 Obfuscated PowerShell Execution Cradle

> Generated by `python scripts/rule_docs.py` from the rule, its playbook and the containment
> catalogue. Edit those sources, not this page.

## What fired

Detects obfuscated or policy-bypassing PowerShell invocations commonly used by download cradles and in-memory stagers, including encoded commands, profile bypass, and hidden windows.

- Severity: **HIGH** · ATT&CK: T1059.001
- Rule file: `rules/sigma/win_powershell_obfuscation.yml` · Data source: Sysmon Event 1 (process creation) / Security 4688 with command line

## Triage

Playbook: `default-triage`.

1. Confirm the alert against the raw telemetry in the incident record
2. Check whether the host, user or source IP appears in other open incidents
3. Decide true or false positive and record why in the analyst notes
4. If false positive, propose a rule exception (rules/exceptions.yml) with an owner and expiry

Fields to check in the event: `CommandLine`, `Image`.

## Response

- Proposed action: `TERMINATE_PROCESS_TREE` (TIER_3_IDENTITY, always needs approval, rollback PARTIAL).
- What it does: Terminates a process tree and locks the user account involved.
- How it can go wrong: A user loses unsaved work and access; locking a shared or service account stops a business process.
- Before approving: collect or check the volatile evidence package on the incident; confirm the target is not a protected asset or account.

## Known false positives

- Legitimate management frameworks (SCCM, Intune) occasionally invoke encoded commands; baseline and allowlist known signers.
- Exception `EXC-0001` in force until 2027-04-30: Signed inventory/maintenance scripts run by the task scheduler (svchost) from C:\Scripts\ with -NoProfile. Assumes C:\Scripts is writable by admins only; if that ACL changes, this entry must go.

## Escalate when

- The activity continues after containment, or appears on a second host or account.
- A protected asset, privileged account or production service is involved.
- You cannot rule out real attacker activity within the playbook's steps.
