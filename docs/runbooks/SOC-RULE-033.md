# Runbook: SOC-RULE-033 AS-REP Roasting: TGT Without Pre-Authentication over RC4

## What fired

Detects Kerberos TGT requests (4768) for accounts without pre-authentication (PreAuthType 0) using RC4, which lets attackers crack the AS-REP offline.

- Severity: **HIGH** · ATT&CK: T1558.004
- Rule file: `rules/sigma/win_asrep_roasting.yml` · Data source: Windows Security log (Advanced Audit Policy)

## Triage

Playbook: `credential-theft`.

1. Identify the process and account that accessed the credential material
2. Collect the volatile evidence package before approving any isolation
3. List accounts with sessions on the host; plan password resets for exposed accounts
4. Check domain controllers for follow-on use (4624 logon type 3/9, 4769 from the same source)

Fields to check in the event: `EventID`, `PreAuthType`, `TicketEncryptionType`.

## Response

- No containment is proposed (`ENRICH_AND_ALERT_ANALYST`): alert and investigate. If you decide to act, propose an action on the incident (`POST /api/incidents/<id>/propose`); it still needs approval.

## Known false positives

- Legacy accounts deliberately configured without Kerberos pre-authentication

## Escalate when

- The activity continues after containment, or appears on a second host or account.
- A protected asset, privileged account or production service is involved.
- You cannot rule out real attacker activity within the playbook's steps.
