## How each bypass could be closed

- **EV-02** (SOC-RULE-004, Abbreviated parameter (-ec)): PowerShell accepts any unambiguous prefix (-e, -ec, -enco). Fix: match a regex such as `\s-e(c|nc|nco|ncod|ncode|ncoded|ncodedc\w*)?\s` instead of fixed strings.
- **EV-03** (SOC-RULE-004, En dash instead of hyphen): PowerShell treats en/em dashes as parameter prefixes. Fix: match `EncodedCommand` without the dash.
- **EV-04** (SOC-RULE-004, Renamed powershell.exe): The rule keys on Image. Fix: also match OriginalFileName (Sysmon records it); tracked in GAPS.md as T1036.003.
- **EV-07** (SOC-RULE-005, Policy registry value via reg.exe): Same effect, different binary. Fix: a registry_set rule on the Defender policy keys (needs Sysmon Event 13).
- **EV-08** (SOC-RULE-001, PROCESS_ALL_ACCESS (0x1FFFFF)): The rule lists 0x1010, 0x1400 and 0x1F0FFF only. Fix: add 0x1FFFFF and other masks with PROCESS_VM_READ (0x10).
- **EV-09** (SOC-RULE-001, Source binary named svchost.exe outside System32): The filter trusts any path ending in \svchost.exe. Fix: filter on the full System32 path.
- **EV-11** (SOC-RULE-019, Two spaces between verb and object): The rule matches the literal 'delete shadows'. Fix: contains|all on 'delete' and 'shadows'.
- **EV-12** (SOC-RULE-019, CIM cmdlets instead of WMI Delete()): The PowerShell branch needs the word 'Delete'. Fix: also accept Remove-CimInstance / Remove-WmiObject.
- **EV-14** (SOC-RULE-039, Renamed rclone, custom remote name): Remote names are user-defined in rclone.conf. Fix: match OriginalFileName/hash of rclone, or network telemetry.
- **EV-15** (SOC-RULE-014, Alternative download verb (-verifyctl)): certutil can fetch URLs with several verbs. Fix: also match 'http' in the command line of certutil.
- **EV-16** (SOC-RULE-014, Renamed certutil.exe): Keyed on Image only. Fix: also match OriginalFileName.

Detected variants are kept as regression checks: they must keep matching.
