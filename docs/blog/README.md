documented detection pipeline, including the parts that did not work. Per-rule detail lives
in the [rule write-ups](../rules/README.md).

1. [From six rules to a real Sigma engine](01-sigma-engine.md)
2. [Correlations: when one event is not enough](02-correlations.md)
3. [Breaking my own rules](03-evasion.md)
4. [Decoys: detections that almost never lie](04-deception.md)
5. [Looking at the network: DNS tunnelling and TLS fingerprints](05-network.md)

The posts were drafted with an AI assistant from the repository's history and edited for
accuracy; numbers come from the generated reports they link to.
