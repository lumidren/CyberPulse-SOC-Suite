## What it detects

A GUARDIAN anomaly alert with a score of 0.8 or more (scores run 0 to 1). GUARDIAN models behaviour such as low-and-slow authentication that threshold rules miss. An anomaly is a statistical signal, not proof, so this rule only alerts.

## How it works

- `selection`: `AnomalyScore` is at least `0.8`
- condition: `selection`

## Telemetry it needs

GUARDIAN anomaly alerts (ML, via /api/ingest/guardian) (logsource `guardian/anomaly`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
