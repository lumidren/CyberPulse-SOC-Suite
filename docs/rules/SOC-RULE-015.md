# SOC-RULE-015: Mshta Executing Remote or Inline Script

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1218.005 · **Version** 1.0.0 · `rules/sigma/win_lolbas_mshta_remote_script.yml` · [Runbook](../runbooks/SOC-RULE-015.md)

## What it detects

Detects mshta.exe executing a remote HTA or inline javascript/vbscript, used to proxy execution of malicious code through a signed binary.

## How it works

- `selection_img`: `Image` ends with `\mshta.exe`
- `selection_cli`: `CommandLine` contains one of `http://`, `https://`, `javascript:`, `vbscript:`
- condition: `selection_img and selection_cli`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
