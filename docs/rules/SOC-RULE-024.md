# SOC-RULE-024: Run Key Persistence Added via reg.exe

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

## What it detects

Detects reg.exe adding a value under a CurrentVersion\Run or RunOnce key, a common way to make malware start at every logon.

## How it works

- `selection`: `Image` ends with `\reg.exe` AND `CommandLine` contains all of ` add `, `\CurrentVersion\Run`
- condition: `selection`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
