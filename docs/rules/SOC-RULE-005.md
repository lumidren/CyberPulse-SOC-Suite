# SOC-RULE-005: Windows Defender Real-Time Protection Disabled via PowerShell

## What it detects

Detects attempts to impair host defenses by disabling Windows Defender real-time monitoring and script scanning via Set-MpPreference or registry modification.

## How it works

- `selection`: `Image` ends with one of `\powershell.exe`, `\pwsh.exe` AND `CommandLine` contains one of `Set-MpPreference`, `-DisableRealtimeMonitoring`, `-DisableBehaviorMonitoring`, `-DisableIOAVProtection`, `-DisableScriptScanning`
- condition: `selection`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
