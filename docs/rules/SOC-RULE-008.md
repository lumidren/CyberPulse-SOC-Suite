# SOC-RULE-008: Active Directory Replication Abuse (DCSync) via Non-DC Account

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1003.006 · **Version** 1.0.1 · `rules/sigma/win_dcsync.yml` · [Runbook](../runbooks/SOC-RULE-008.md)

## What it detects

Detects directory replication service requests (DS-Replication-Get-Changes) originating from non-domain controller accounts, indicative of Mimikatz lsadump::dcsync credential harvesting.

## How it works

- `selection`: `EventID` equals `4662` AND `AccessMask` equals `0x100` AND `Properties` contains one of `1131f6aa-9c07-11d1-f79f-00c04fc2dcd2`, `1131f6ad-9c07-11d1-f79f-00c04fc2dcd2`
- `filter`: `SubjectUserName` ends with `$`
- condition: `selection and not filter`

Windows Security log (Advanced Audit Policy) (logsource `windows/security`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
