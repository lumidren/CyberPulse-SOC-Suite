# SOC-RULE-046: Authentication Attempt Against a Honey Account

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1078.002, T1110 · **Version** 1.0.0 · `rules/sigma/win_honey_account_activity.yml` · [Runbook](../runbooks/SOC-RULE-046.md)

## What it detects

Any logon, Kerberos ticket request or failed logon for a decoy account. Honey accounts are never used legitimately, so any activity means someone enumerated and tried them. Replace the lab names with the decoy accounts you create (see docs/CANARIES.md).

## How it works

- `selection_events`: `EventID` equals one of `4624`, `4625`, `4648`, `4768`, `4769`, `4771`, `4776`
- `selection_users`: `TargetUserName` equals one of `svc_sql_legacy`, `adm_backup_old`
- condition: `selection_events and selection_users`
