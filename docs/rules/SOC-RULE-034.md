# SOC-RULE-034: Active Directory Reconnaissance Commands

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

## What it detects

Detects enumeration of privileged groups and domain trusts with net, nltest or AdFind, typical of an intruder mapping the domain before escalating.

## How it works

- `selection_net`: `Image` ends with one of `\net.exe`, `\net1.exe` AND `CommandLine` contains one of `group "domain admins"`, `group "enterprise admins"`, `group domain admins`
- `selection_nltest`: `Image` ends with `\nltest.exe` AND `CommandLine` contains one of `/domain_trusts`, `/dclist`
- `selection_adfind`: `CommandLine` contains one of `adfind`, `-sc trustdmp`, `objectcategory=person`
- condition: `1 of selection_*`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
