# SOC-RULE-018: BITSAdmin Download or Job Creation

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** medium · **ATT&CK** T1197 · **Version** 1.0.0 · `rules/sigma/win_lolbas_bitsadmin_transfer.yml` · [Runbook](../runbooks/SOC-RULE-018.md)

## What it detects

Detects bitsadmin.exe creating or running transfer jobs, which attackers use to download payloads and to persist via BITS job notify commands.

## How it works

- `selection_img`: `Image` ends with `\bitsadmin.exe`
- `selection_cli`: `CommandLine` contains one of `/transfer`, `/addfile`, `/SetNotifyCmdLine`, `/download`
- condition: `selection_img and selection_cli`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).

## Tuning

- Expected false positive: Legacy software update scripts that still use bitsadmin (most use BITS PowerShell cmdlets now)
