# SOC-RULE-028: UAC Bypass via ms-settings Shell Open Command

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

## What it detects

Detects a write to HKCU ...\ms-settings\shell\open\command (Sysmon 13), used with fodhelper.exe or computerdefaults.exe to run a program elevated without a UAC prompt.

## How it works

- `selection`: `TargetObject` contains `\ms-settings\shell\open\command`
- condition: `selection`

## Telemetry it needs
