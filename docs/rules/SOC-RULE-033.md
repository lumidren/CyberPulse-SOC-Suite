# SOC-RULE-033: AS-REP Roasting: TGT Without Pre-Authentication over RC4

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1558.004 · **Version** 1.0.0 · `rules/sigma/win_asrep_roasting.yml` · [Runbook](../runbooks/SOC-RULE-033.md)

## What it detects

Detects Kerberos TGT requests (4768) for accounts without pre-authentication (PreAuthType 0) using RC4, which lets attackers crack the AS-REP offline.

## How it works

- `selection`: `EventID` equals `4768` AND `PreAuthType` equals `0` AND `TicketEncryptionType` equals `0x17`
- condition: `selection`

## Telemetry it needs

Windows Security log (Advanced Audit Policy) (logsource `windows/security`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
