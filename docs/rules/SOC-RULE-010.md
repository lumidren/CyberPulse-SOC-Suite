## What it detects

Detects impossible travel login anomalies in Microsoft Entra ID (Azure AD) where user authentications originate from geographically disparate IP addresses within an unrealistic physical travel window.

## How it works

- `selection`: `Category` equals `SignInLogs` AND `OperationName` equals `Sign-in activity` AND `ResultType` equals `0`
- `anomaly`: `RiskLevelDuringSignIn` equals `high` AND `RiskEventTypes` contains `impossibleTravel`
- condition: `selection and anomaly`

## Telemetry it needs

Entra ID sign-in logs (logsource `azure/signinlogs`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
