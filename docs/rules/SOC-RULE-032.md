# SOC-RULE-032: NTDS.dit Extraction via ntdsutil IFM

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1003.003 · **Version** 1.0.0 · `rules/sigma/win_ntds_extraction.yml` · [Runbook](../runbooks/SOC-RULE-032.md)

## What it detects

Detects ntdsutil.exe creating an Install-From-Media copy (ifm create full), which produces a copy of NTDS.dit with every domain password hash.

## How it works

- `selection`: `Image` ends with `\ntdsutil.exe` AND `CommandLine` contains all of `ifm`, `create`
- condition: `selection`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
