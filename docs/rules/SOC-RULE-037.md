# SOC-RULE-037: Remote Access Tool Started from a User-Writable Path

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** medium · **ATT&CK** T1219 · **Version** 1.0.0 · `rules/sigma/win_remote_access_tool.yml` · [Runbook](../runbooks/SOC-RULE-037.md)

## What it detects

Detects AnyDesk, TeamViewer, ScreenConnect, Atera or similar remote-access tools running from Downloads, Temp, AppData or Public, often installed by intruders for persistent hands-on access.

## How it works

- `selection_tool`: `Image` ends with one of `\AnyDesk.exe`, `\TeamViewer.exe`, `\ScreenConnect.ClientService.exe`, `\AteraAgent.exe`, `\rustdesk.exe`
- `selection_path`: `Image` contains one of `\Downloads\`, `\Temp\`, `\AppData\`, `\Users\Public\`
- condition: `selection_tool and selection_path`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
