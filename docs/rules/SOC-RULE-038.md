# SOC-RULE-038: Password-Protected Archive Created with 7-Zip or WinRAR

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** medium · **ATT&CK** T1560.001 · **Version** 1.0.0 · `rules/sigma/win_archive_with_password.yml` · [Runbook](../runbooks/SOC-RULE-038.md)

## What it detects

Detects 7-Zip or WinRAR creating an archive with a password (-p), a typical staging step before exfiltrating collected data.

## How it works

- `selection_img`: `Image` ends with one of `\7z.exe`, `\7za.exe`, `\rar.exe`, `\WinRAR.exe`
- `selection_add`: `CommandLine` contains one of ` a `, ` -a `
- `selection_password`: `CommandLine` contains one of ` -p`, ` -hp`
- condition: `all of selection_*`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
