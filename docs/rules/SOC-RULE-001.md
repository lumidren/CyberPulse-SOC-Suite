# SOC-RULE-001: OS Credential Dumping via LSASS Memory Access

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1003.001 · **Version** 1.0.1 · `rules/sigma/win_lsass_dumping.yml` · [Runbook](../runbooks/SOC-RULE-001.md)

## What it detects

Detects process access requests targeting lsass.exe memory space (GrantedAccess 0x1010 or 0x1400), indicative of Mimikatz or ProcDump credential dumping.

## How it works

- `selection`: `TargetImage` ends with `\lsass.exe` AND `GrantedAccess` contains one of `0x1010`, `0x1400`, `0x1F0FFF`
- `filter`: `SourceImage` ends with one of `\svchost.exe`, `\csrss.exe`, `\MsMpEng.exe`
- condition: `selection and not filter`

## Telemetry it needs

Sysmon Event 10 (process access) (logsource `windows/process_access`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
