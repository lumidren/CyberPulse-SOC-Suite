# SOC-RULE-041: AWS CloudTrail Logging Stopped or Deleted

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1562.008 · **Version** 1.0.0 · `rules/sigma/cloud_aws_cloudtrail_disabled.yml` · [Runbook](../runbooks/SOC-RULE-041.md)

## What it detects

Detects StopLogging, DeleteTrail or an UpdateTrail that disables multi-region logging in CloudTrail, which attackers use to blind defenders in an AWS account.

## How it works

- `selection`: `eventSource` equals `cloudtrail.amazonaws.com` AND `eventName` equals one of `StopLogging`, `DeleteTrail`
- condition: `selection`

## Telemetry it needs

AWS CloudTrail (management events) (logsource `aws/cloudtrail`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
