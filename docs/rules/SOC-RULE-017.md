# SOC-RULE-017: Rundll32 Executing Script or Remote Content

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1218.011 · **Version** 1.0.0 · `rules/sigma/win_lolbas_rundll32_script.yml` · [Runbook](../runbooks/SOC-RULE-017.md)

## What it detects

Detects rundll32.exe abused to run javascript through mshtml (RunHTMLApplication) or to load content from a URL, proxying execution through a signed binary.

## How it works

- `selection_img`: `Image` ends with `\rundll32.exe`
- `selection_cli`: `CommandLine` contains one of `javascript:`, `RunHTMLApplication`, `http://`, `https://`
- condition: `selection_img and selection_cli`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
