# SOC-RULE-025: Service Installed from a Suspicious Path or Command

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1543.003 · **Version** 1.0.0 · `rules/sigma/win_service_install_suspicious_path.yml` · [Runbook](../runbooks/SOC-RULE-025.md)

## What it detects

Detects new services (System 7045) whose image path is in a user-writable location or launches a script interpreter, used for persistence and privilege escalation.

## How it works

- `selection`: `EventID` equals `7045`
- `suspicious`: `ImagePath` contains one of `\Temp\`, `\Users\Public\`, `\AppData\`, `powershell`, `cmd.exe /c`, `mshta`
- condition: `selection and suspicious`

## Telemetry it needs

Windows System log (Service Control Manager) (logsource `windows/system`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
