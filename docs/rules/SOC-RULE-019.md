# SOC-RULE-019: Volume Shadow Copy Deletion or Resizing

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1490 · **Version** 1.0.0 · `rules/sigma/win_ransomware_shadow_copy_deletion.yml` · [Runbook](../runbooks/SOC-RULE-019.md)

## What it detects

Detects deletion or shrinking of Volume Shadow Copies via vssadmin, wmic or PowerShell, done by ransomware just before encryption so files cannot be restored.

## How it works

- `selection_vssadmin`: `Image` ends with `\vssadmin.exe` AND `CommandLine` contains one of `delete shadows`, `resize shadowstorage`
- `selection_wmic`: `Image` ends with `\wmic.exe` AND `CommandLine` contains all of `shadowcopy`, `delete`
- `selection_powershell`: `Image` ends with one of `\powershell.exe`, `\pwsh.exe` AND `CommandLine` contains all of `Win32_ShadowCopy`, `Delete`
- condition: `1 of selection_*`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
