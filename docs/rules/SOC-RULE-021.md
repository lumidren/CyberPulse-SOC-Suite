# SOC-RULE-021: Office Application Spawning a Shell or Script Host

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1566.001, T1204.002 · **Version** 1.0.0 · `rules/sigma/win_office_spawns_shell.yml` · [Runbook](../runbooks/SOC-RULE-021.md)

## What it detects

Detects Word, Excel, PowerPoint or Outlook starting cmd, PowerShell, wscript, cscript or mshta, the usual first step of a malicious macro or phishing attachment.

## How it works

- `selection_parent`: `ParentImage` ends with one of `\WINWORD.EXE`, `\EXCEL.EXE`, `\POWERPNT.EXE`, `\OUTLOOK.EXE`
- `selection_child`: `Image` ends with one of `\cmd.exe`, `\powershell.exe`, `\pwsh.exe`, `\wscript.exe`, `\cscript.exe`, `\mshta.exe`
- condition: `selection_parent and selection_child`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
