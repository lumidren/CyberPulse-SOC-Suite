# SOC-RULE-030: Windows Firewall Disabled via netsh or PowerShell

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

## What it detects

Detects the host firewall being turned off for all profiles with netsh advfirewall or Set-NetFirewallProfile -Enabled False.

## How it works

- `selection_netsh`: `Image` ends with `\netsh.exe` AND `CommandLine` contains all of `advfirewall`, `state off`
- `selection_ps`: `CommandLine` contains all of `Set-NetFirewallProfile`, `-Enabled`, `False`
- condition: `1 of selection_*`
