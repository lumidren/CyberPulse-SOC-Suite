# SOC-RULE-016: Regsvr32 Loading a Remote Scriptlet (Squiblydoo)

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1218.010 · **Version** 1.0.0 · `rules/sigma/win_lolbas_regsvr32_squiblydoo.yml` · [Runbook](../runbooks/SOC-RULE-016.md)

## What it detects

Detects regsvr32.exe loading a remote COM scriptlet through scrobj.dll (/i:http...), which executes code while bypassing application allowlisting.

## How it works

- `selection_img`: `Image` ends with `\regsvr32.exe`
- `selection_remote`: `CommandLine` contains one of `/i:http`, `-i:http`, `/i:ftp`
- `selection_scrobj`: `CommandLine` contains `scrobj`
- condition: `selection_img and selection_remote and selection_scrobj`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
