# SOC-RULE-022: Process Creation via WMIC process call create

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

## What it detects

Detects wmic.exe used to start a process locally or on a remote host (process call create), a common execution and lateral-movement technique.

## How it works

- `selection`: `Image` ends with `\wmic.exe` AND `CommandLine` contains all of `process`, `call`, `create`
- condition: `selection`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
