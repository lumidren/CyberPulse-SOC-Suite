# SOC-RULE-031: SAM or SYSTEM Registry Hive Saved to Disk

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1003.002 · **Version** 1.0.0 · `rules/sigma/win_sam_hive_export.yml` · [Runbook](../runbooks/SOC-RULE-031.md)

## What it detects

Detects reg.exe saving the SAM, SECURITY or SYSTEM hive (reg save), which lets an attacker extract local password hashes offline.

## How it works

- `selection`: `Image` ends with `\reg.exe` AND `CommandLine` contains one of `save hklm\sam`, `save hklm\system`, `save hklm\security`
- condition: `selection`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
