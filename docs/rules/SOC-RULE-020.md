# SOC-RULE-020: Backup Catalog Deletion or Boot Recovery Disabled

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** critical · **ATT&CK** T1490 · **Version** 1.0.0 · `rules/sigma/win_ransomware_recovery_inhibition.yml` · [Runbook](../runbooks/SOC-RULE-020.md)

## What it detects

Detects deletion of the Windows backup catalog (wbadmin delete catalog) or disabling of boot recovery (bcdedit recoveryenabled no / ignoreallfailures), typical ransomware preparation.

## How it works

- `selection_wbadmin`: `Image` ends with `\wbadmin.exe` AND `CommandLine` contains one of `delete catalog`, `delete systemstatebackup`
- `selection_bcdedit`: `Image` ends with `\bcdedit.exe` AND `CommandLine` contains one of `recoveryenabled no`, `bootstatuspolicy ignoreallfailures`
- condition: `1 of selection_*`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
