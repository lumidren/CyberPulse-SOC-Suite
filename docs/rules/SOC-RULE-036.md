# SOC-RULE-036: Shell Spawned by WinRM Remote Session Host

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** medium · **ATT&CK** T1021.006 · **Version** 1.0.0 · `rules/sigma/win_winrm_remote_shell.yml` · [Runbook](../runbooks/SOC-RULE-036.md)

## What it detects

Detects cmd or PowerShell started by wsmprovhost.exe, i.e. commands run over a WinRM/PowerShell Remoting session, a common lateral-movement channel.

## How it works

- `selection`: `ParentImage` ends with `\wsmprovhost.exe` AND `Image` ends with one of `\cmd.exe`, `\powershell.exe`, `\whoami.exe`, `\net.exe`
- condition: `selection`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
