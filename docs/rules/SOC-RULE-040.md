# SOC-RULE-040: Backup or Security Service Stopped via net or sc

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1489 · **Version** 1.0.0 · `rules/sigma/win_service_stop_backup_security.yml` · [Runbook](../runbooks/SOC-RULE-040.md)

## What it detects

Detects net stop / sc stop against backup, database, shadow-copy or security services, which ransomware runs before encryption to release file locks and blind defenders.

## How it works

- `selection_img`: `Image` ends with one of `\net.exe`, `\net1.exe`, `\sc.exe`
- `selection_stop`: `CommandLine` contains one of `stop`, `config`
- `selection_target`: `CommandLine` contains one of `veeam`, `backup`, `vss`, `sql`, `WinDefend`, `sophos`, `MsMpSvc`, `wbengine`
- condition: `all of selection_*`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
