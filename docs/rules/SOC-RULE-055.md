# SOC-RULE-055: TLS Client Fingerprint on the Local JA3/JA4 Blocklist

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1071.001, T1573.002 · **Version** 1.0.0 · `rules/sigma/net_zeek_tls_fingerprint_blocklist.yml` · [Runbook](../runbooks/SOC-RULE-055.md)

## What it detects

A TLS client whose JA3 or JA4 fingerprint is on the blocklist in this rule. The shipped values are SYNTHETIC LAB PLACEHOLDERS, not real malware fingerprints: load your own list (for example the abuse.ch SSLBL JA3 list) with scripts/update_tls_blocklist.py. A fingerprint identifies a TLS library and its settings, not a program, so legitimate software can share one.

## How it works

- `selection_ja3`: `ja3` equals one of `0000000000000000000000000000c0de`, `0000000000000000000000000000beef`
- `selection_ja4`: `ja4` equals `t00d0000h0_000000000000_00000000c0de`
- condition: `1 of selection_*`
