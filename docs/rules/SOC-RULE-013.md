# SOC-RULE-013: Possible Golden Ticket Use via Kerberos Logon Domain Anomaly

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

## What it detects

Heuristic for forged Kerberos TGTs (golden tickets): a Kerberos network logon (4624) whose TargetDomainName is not one of the domain's expected NetBIOS names. Ticket-forging tools often fill the domain field with an FQDN, lowercase or arbitrary value. The filter lists the lab's expected domains and must be tuned per environment.

## How it works

- `selection`: `EventID` equals `4624` AND `LogonType` equals `3` AND `AuthenticationPackageName` equals `Kerberos`
- `filter_expected_domain`: `TargetDomainName` matches regex `^(CORP|NT AUTHORITY)$`
- condition: `selection and not filter_expected_domain`

## Tuning

- Expected false positive: Logons from trusted domains or forests not listed in the filter (add their NetBIOS names)
- Expected false positive: Applications that report the FQDN instead of the NetBIOS domain name
