## What it detects

Detects tenant-wide admin consent being granted to an application in Entra ID audit logs, a path to persistent OAuth access (illicit consent grant).

## How it works

- `selection`: `OperationName` equals `Consent to application` AND `ConsentType` contains `AllPrincipals`
- condition: `selection`

## Telemetry it needs

Entra ID audit logs (logsource `azure/auditlogs`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
