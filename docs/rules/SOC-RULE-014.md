# SOC-RULE-014: Certutil Used to Download or Decode a Payload

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1105, T1140 · **Version** 1.0.0 · `rules/sigma/win_lolbas_certutil_download.yml` · [Runbook](../runbooks/SOC-RULE-014.md)

## What it detects

Detects certutil.exe used as a downloader (-urlcache -split -f) or to decode base64 payloads (-decode), a common living-off-the-land technique.

## How it works

- `selection_img`: `Image` ends with `\certutil.exe`
- `selection_cli`: `CommandLine` contains one of `urlcache`, `-decode`, `/decode`, `-decodehex`
- condition: `selection_img and selection_cli`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).
