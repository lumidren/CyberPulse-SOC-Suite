# SOC-RULE-004: Obfuscated PowerShell Execution Cradle

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1059.001 · **Version** 1.0.1 · `rules/sigma/win_powershell_obfuscation.yml` · [Runbook](../runbooks/SOC-RULE-004.md)

## What it detects

Detects obfuscated or policy-bypassing PowerShell invocations commonly used by download cradles and in-memory stagers, including encoded commands, profile bypass, and hidden windows.

## How it works

- `selection_img`: `Image` ends with one of `\powershell.exe`, `\pwsh.exe`
- `selection_flags`: `CommandLine` contains one of `-EncodedCommand`, `-enc `, `-nop`, `-NoProfile`, `-WindowStyle Hidden`, `IEX(`, `Invoke-Expression`, `DownloadString`
- condition: `selection_img and selection_flags`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).

## Evidence it works (synthetic data only)

## Tuning

- Expected false positive: Legitimate management frameworks (SCCM, Intune) occasionally invoke encoded commands; baseline and allowlist known signers.
- Prefer an expiring exception for one known-benign pattern; change the logic (with a version bump) only when it is wrong for everyone. See [TUNING.md](../TUNING.md).
