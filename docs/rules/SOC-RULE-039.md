# SOC-RULE-039: Rclone Copying Data to Cloud Storage

> Generated by `python scripts/rule_docs.py` from the rule and the test evidence.

**Level** high · **ATT&CK** T1567.002 · **Version** 1.0.0 · `rules/sigma/win_rclone_exfiltration.yml` · [Runbook](../runbooks/SOC-RULE-039.md)

## What it detects

Detects rclone (including renamed copies identified by its flags) copying or syncing data to remote cloud storage, a favourite exfiltration tool of ransomware operators.

## How it works

- `selection_img`: `Image` ends with `\rclone.exe` AND `CommandLine` contains one of ` copy `, ` sync `, ` move `
- `selection_flags`: `CommandLine` contains all of `--config`, `--no-check-certificate`
- `selection_remote`: `CommandLine` contains one of `mega:`, `s3:`, `drive:`, `dropbox:`, `ftp:` AND `CommandLine` contains all of ` copy `
- condition: `1 of selection_*`

## Telemetry it needs

Sysmon Event 1 (process creation) / Security 4688 with command line (logsource `windows/process_creation`). If that source is not collected, the rule cannot fire: see [DATA_SOURCES.md](../coverage/DATA_SOURCES.md).

## Tuning
