# Code of Conduct

CyberPulse SOC Suite is a defensive security lab. People who contribute, file issues or
discuss it are expected to make it a respectful, welcoming place for everyone, whatever
their experience, background or identity.

## Expected behaviour

- Be kind and patient, especially with people who are learning.
- Critique code, rules and ideas, not people. Explain *why* when you disagree.
- Assume good intent, and ask before assuming a mistake was malicious.
- Credit other people's work, including detection logic and research you build on.
- Report security problems privately, as described in [SECURITY.md](SECURITY.md).

## Unacceptable behaviour

- Harassment, insults, discriminatory jokes or language, and personal attacks.
- Publishing someone's private information without their explicit permission.
- Sharing, requesting or contributing material that would help attack systems their
  owner has not authorised you to test: working malware, credential-theft tooling,
  exploit chains against real targets, or stolen data. This project emits telemetry only
  (see [CONTRIBUTING.md](CONTRIBUTING.md)).
- Posting real logs, telemetry, credentials or incident data from any organisation.
- Sustained disruption of discussions, issues or reviews.

## Scope

This applies in the repository (issues, pull requests, reviews, discussions) and anywhere
someone represents the project.

## Enforcement

Report problems to the maintainer through a private GitHub security advisory on this
repository, or by contacting the maintainer (`lumidren`) through GitHub. Reports are kept
confidential. The maintainer may remove content, ask for changes, or restrict or ban
participation, in proportion to the problem, and will explain the decision to the
person involved.

This code is based on the ideas of the
[Contributor Covenant](https://www.contributor-covenant.org/), written in our own words.
